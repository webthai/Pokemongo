# Raid Terminal — Pokémon GO Dashboard

เว็บแดชบอร์ดหน้าเดียวที่รวม **บอสเรดปัจจุบัน**, **Community Day ล่าสุด**, และ **โบนัสสภาพอากาศ** ของ Pokémon GO ไว้ในที่เดียว เป็น static site ล้วนๆ (HTML/CSS/JS) ไม่มี backend ไม่มีฐานข้อมูลของตัวเอง — ข้อมูลทั้งหมดดึงมาจาก [PoGo API](https://pogoapi.net) ซึ่งเป็น API สาธารณะที่ทำโดยชุมชน (ไม่ใช่ของ Niantic อย่างเป็นทางการ) ณ เวลาที่ผู้ใช้เปิดหน้าเว็บ

## มีอะไรให้ดูบ้าง

- **บอสเรดปัจจุบัน** — แบ่งตาม Tier 1–6 และ Mega กดแท็บสลับดูได้ แต่ละใบการ์ดโชว์ธาตุ, ช่วง CP ปกติ/ตอนอากาศบูสต์, สภาพอากาศที่บูสต์บอสตัวนั้น และบอกว่ามีโอกาสเจอเชนี่ไหม มีสวิตช์สลับไปดู "รอบก่อนหน้า" ได้ด้วย
- **Community Day** — ข้อมูลอีเวนต์ล่าสุด: โปเกมอนพิเศษ, โบนัสของวันนั้น, ท่าไม้ตายพิเศษที่หาได้เฉพาะช่วงอีเวนต์
- **โบนัสสภาพอากาศ** — ตารางอ้างอิงว่าอากาศแบบไหนบูสต์ธาตุอะไรบ้าง
- นาฬิกาบนหัวเว็บเป็นเวลาไทย (Asia/Bangkok, UTC+7) เสมอ

## ทำไมถึงไม่ต้องตั้งค่าอะไรเลย

เพราะเว็บนี้ไม่มีระบบล็อกอิน ไม่มีฐานข้อมูลของตัวเอง และไม่ต้องมี API key — มันแค่ยิง `fetch()` ไปที่ API สาธารณะของ PoGo API ตรงๆ จากเบราว์เซอร์ของผู้ใช้ทุกครั้งที่เปิดหน้าเว็บ ทำให้ deploy ขึ้น GitHub Pages ได้เลยแบบไม่ต้องแก้โค้ดอะไรก่อน

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บทั้งหมด |
| `style.css` | ธีมและ layout (โทนมืด, ธีม "เทอร์มินัลล่าเรด") |
| `app.js` | ดึงข้อมูลจาก API, render การ์ดต่างๆ, นาฬิกา, ปุ่มรีเฟรช |
| `README.md` | ไฟล์นี้ |

## วิธี Deploy ขึ้น GitHub Pages (ฟรี)

### ขั้นตอนที่ 1 — สร้าง Repository
1. เข้า [github.com](https://github.com) แล้วกด **New repository**
2. ตั้งชื่อ เช่น `pogo-raid-dashboard`
3. เลือก **Public**
4. กด **Create repository**

### ขั้นตอนที่ 2 — อัปโหลดไฟล์
1. ในหน้า repository ที่เพิ่งสร้าง กด **Add file → Upload files**
2. ลากไฟล์ทั้ง 3 ไฟล์เข้าไป: `index.html`, `style.css`, `app.js` (จะอัปโหลด `README.md` ด้วยก็ได้)
3. กด **Commit changes**

### ขั้นตอนที่ 3 — เปิดใช้งาน GitHub Pages
1. ไปที่แท็บ **Settings** ของ repository
2. เมนูซ้ายเลือก **Pages**
3. ใต้หัวข้อ **Build and deployment** → **Source** เลือก **Deploy from a branch**
4. **Branch** เลือก `main` และโฟลเดอร์เลือก `/ (root)` แล้วกด **Save**
5. รอประมาณ 1-2 นาที แล้วรีเฟรชหน้า Settings → Pages อีกครั้ง จะเห็นลิงก์ประมาณ:
   ```
   https://<ชื่อผู้ใช้ของคุณ>.github.io/pogo-raid-dashboard/
   ```
6. เข้าลิงก์นั้นได้เลย เว็บพร้อมใช้งานทันที

> ไม่ต้องตั้งค่า Apps Script, ไม่ต้องมี Google Sheet, ไม่ต้อง deploy อะไรเพิ่มอีก เพราะเว็บนี้ไม่มี backend ของตัวเอง

## การแก้ไข/ปรับแต่งภายหลัง

- อยากเปลี่ยนสีธีม → แก้ตัวแปรใน `:root { ... }` ที่บรรทัดต้นๆ ของ `style.css`
- อยากเปลี่ยนแหล่งข้อมูล → แก้ค่า `API_BASE` ที่ต้นไฟล์ `app.js`
- ทุกครั้งที่แก้ไฟล์แล้วอัปโหลดใหม่ (หรือ push ผ่าน git) GitHub Pages จะอัปเดตเว็บให้อัตโนมัติภายในไม่กี่นาที ไม่ต้อง deploy ซ้ำแบบ Apps Script

## ข้อจำกัดที่ควรรู้

- ข้อมูลบอสเรดและ Community Day มาจาก **PoGo API ซึ่งเป็นโปรเจกต์ชุมชน ไม่ใช่ช่องทางทางการของ Niantic** ความถูกต้อง/ความไวของข้อมูลขึ้นกับผู้ดูแล API นั้น ไม่ได้การันตีว่าจะตรงกับในเกม 100% เสมอไป
- ถ้า PoGo API ล่มหรือเปลี่ยนโครงสร้างข้อมูล เว็บนี้อาจโหลดไม่ขึ้นชั่วคราว — กดปุ่มรีเฟรช (มุมขวาบน) เพื่อลองใหม่ได้
- รูปสไปรท์โปเกมอนดึงจาก mirror สาธารณะของชุมชน (PokeAPI sprites) หากบางตัวไม่มีรูป การ์ดจะซ่อนรูปแทนที่จะพังทั้งการ์ด
- นี่คือเครื่องมือของแฟนเกม (fan tool) ไม่มีความเกี่ยวข้องกับ Niantic หรือ The Pokémon Company
